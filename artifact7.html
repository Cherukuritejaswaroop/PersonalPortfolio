Artifact 7

Inside a Neural Network: Six Components, One Learning Loop

A 13-slide visual presentation that explains the six building blocks of a neural network and tests them through my own experiments in the TensorFlow Neural Network Playground.

View Slides (PDF) Download PowerPoint

Artifact Information

This artifact is a visual presentation that defines layers, neurons, weights, activation functions, loss functions, and optimization algorithms, shows how they work together as one learning loop, and reports the results of five experiments I ran in the TensorFlow Playground.

Introduction

Neural networks power image recognition, language models, and many prediction systems, but their inner workings can feel like a black box. This presentation opens that box one component at a time, using diagrams, calculated examples, and real training results instead of long text.

Description

The deck starts with an architecture diagram showing how data flows from the input layer through two hidden layers to the output, matching the Playground's default network (2 inputs, 4 and 2 hidden neurons, 1 output). One slide is given to each of the six components, each with a definition, its role, and a visual: a worked neuron calculation, activation curves plotted from their formulas, a cross-entropy loss chart, and a gradient descent chart comparing learning rates of 0.3 and 1.1.

The final section connects the components into the learning loop and presents my own Playground results. Across five runs, test loss ranged from 0.004 on clean circle data to 0.474 on spiral data with a Linear activation, and a larger network (four hidden layers of 6 neurons) reduced spiral test loss from 0.452 to 0.295.

Objective

  • Clearly define and describe the six key components of a neural network
  • Visually show how data flows from the input layer through hidden layers to the output
  • Test how noise, network size, and activation functions affect training, using real experiments
  • Explain complex AI concepts concisely for both technical and non-technical audiences

Process

  • Reviewed course resources and Google's Machine Learning Crash Course on neural networks
  • Ran five experiments in the TensorFlow Playground, changing one setting at a time: noise, dataset, network size, and activation function
  • Recorded the exact settings, epoch, training loss, and test loss of every run from my screenshots
  • Designed one slide per component, each with a diagram or chart, using the Playground's colors (teal for positive weights, orange for negative)
  • Calculated every example chart from its formula and labeled illustrative diagrams so nothing is presented as a result that was not measured
  • Checked every number on the slides against my screenshots and cited each source on the slide where it is used

Tools and Technologies Used

TensorFlow Playground PowerPoint (.pptx) Claude (AI Assistant) Data Visualization Information Design

Value Proposition

This artifact shows that I can learn a technical system hands-on, test it with controlled experiments, and explain what I found in a short, visual way that decision-makers can follow.

Unique Value: While my previous artifact compared many algorithms at a high level, this one goes deep into a single model type and backs its explanations with my own measured results, showing experimentation as well as explanation.

Relevance: Data analysis and AI roles regularly require explaining how a model works and why it performs well or poorly. Presenting results with clear charts and plain language is the same skill used in dashboard design and stakeholder reporting.
